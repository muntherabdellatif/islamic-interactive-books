# هيكلية المشروع (Project Directory & Architecture Structure)

يوثق هذا الملف الهيكل العام لمجلدات وملفات مشروع **منصة التراث الإسلامي التفاعلي** ومسؤولية كل جزء منها.

```
islamic-interactive-books/
├── .agents/                          # إعدادات مخصصة لبيئة وكلاء الذكاء الاصطناعي (Antigravity)
│   └── skills/                       # المهارات الذاتية المكتشفة للنظام
│       ├── image-optimizer/          # مهارة تحسين وضغط صور الصفحات بصيغة WebP
│       ├── vision-html-transcription/# مهارة استخراج النصوص وتوليد HTML مطابق للشكل
│       ├── entity-extraction-linking/# مهارة استخراج الكيانات والربط بالـ UUIDs
│       ├── entity-resolution/        # مهارة توحيد وتطبيع الأسماء والرواة
│       └── interactive-builder/      # مهارة بناء المكونات التفاعلية (Graphs/Trees)
│
├── constants/                        # الثوابت المركزية العامة للمشروع
│   └── pipeline.ts                   # أحجام الحزم والصفحات وأسماء المراحل
│
├── types/                            # تعريفات ونماذج TypeScript الصارمة
│   └── pipeline.ts                   # واجهات البيانات لصفحات الكتاب والحزم
│
├── data/                             # البيانات التراثية والمصادر المرجعية
│   └── books/                        # مجلد الكتب المستهدفة
│       └── al-nashr/                 # كتاب النشر في القراءات العشر (ابن الجزري)
│           ├── images/               # صور الصفحات المحسّنة (985 صفحة WebP)
│           ├── pdf/                  # النسخ المرجعية الأصلية بصيغة PDF (المجلد 1 و 2)
│           ├── source/               # النصوص المفرغة بصيغة Markdown
│           ├── formatted-data/       # الكيانات المهيكلة بصيغة JSON
│           ├── raw-data/             # البيانات الأولية المستخرجة
│           └── mapper.json           # خريطة الفهرسة والربط
│
├── pipeline/                         # خط الإنتاج البرمجي (مقسم لكل مرحلة دون أرقام)
│   ├── templates/                    # قوالب الـ HTML للكتب
│   │   └── al_nashr.html             # قالب كتاب النشر
│   ├── transcription/                # مرحلة استخراج وتحويل الصفحات إلى HTML
│   │   └── processor.ts              # معالج توليد وتطبيق قالب الصفحات
│   ├── extraction/                   # مرحلة استخراج الكيانات والـ UUIDs
│   ├── resolution/                   # مرحلة توحيد ومطابقة الأعلام والرواة
│   ├── interactive/                  # مرحلة توليد المكونات التفاعلية
│   └── status.md                     # تتبع حالة الكتاب الحالي وتدقيق الحزم
│
├── skills/                           # المهارات المرجعية للمطورين
├── about.md                          # الرؤية العامة للمنصة، التصنيفات، وهندسة تجربة المستخدم
├── pipeline.md                       # المعمارية الفنية التفصيلية لخط الإنتاج
├── code-standards.md                 # معايير جودة الكود، قاعدة الـ 300 سطر، وصرامة TypeScript
├── AGENTS.md                         # قواعد وإرشادات صارمة لوكلاء الذكاء الاصطناعي
└── structure.md                      # هذا الملف: المرجع الكامل لهيكلية المستودع
```
