# مهارة استخراج الكيانات والربط الدلالي (Entity Extraction & Linking Skill)

تتولى هذه المهارة قراءة صفحات الـ HTML المعتمدة من المرحلة الأولى، وتحويل النصوص إلى كائنات بيانات مهيكلة وربطها بنص الصفحة بمحددات موضع دقيقة.

---

## 🏗️ نموذج البيانات العام (Entity Schema)

كل كيان مستخرج يجب أن يلتزم بالنموذج التالي:

```typescript
export interface ExtractedEntity {
  id: string; // UUID v4 فريد
  type: 'narrator' | 'book_source' | 'fiqh_rule' | 'tajweed_rule' | 'concept';
  raw_text: string; // النص كما ورد تماماً في الصفحة
  normalized_text: string; // النص بدون حركات وزوائد للمطابقة
  page_number: number;
  dom_anchor: {
    block_id: string;
    start_offset: number;
    end_offset: number;
  };
  metadata: Record<string, unknown>; // خصائص إضافية (سنة الوفاة، الكنية، المذهب، نوع الحكم)
}
```

---

## 🔗 آلية الوسم والربط داخل الـ HTML

عند استخراج كيان مثل راوٍ في إسناد، يتم تحديث كود الـ HTML لتغليف النص بالمعرف الفريد:

```html
<!-- قبل الربط -->
<p>وهو قرأ بها على الشيخ الإمام أبي الحسن طاهر بن غلبون</p>

<!-- بعد الربط -->
<p>
  وهو قرأ بها على الشيخ الإمام 
  <span class="entity-narrator" data-entity-id="9b12a845-0d41-4c6e-825b-3a78912e0833" data-entity-type="narrator">
    أبي الحسن طاهر بن غلبون
  </span>
</p>
```

---

## 🤖 إرشادات التحليل الذكي للذكاء الاصطناعي:
1. **في كتب الأسانيد:** استخراج (الطالب، الشيخ، صيغة الأداء: "قرأ بها على"، "حدثنا"، "أخبرنا"، "بالسند المذكور").
2. **في كتب الفقه:** استخراج (المسألة الفقهية، الحكم: واجب/مندوب/حرام/مكروه/مباح، الشرط أو القيد، الدليل إن وُجد).
3. **في كتب التجويد:** استخراج (الحكم التجويدي، الحروف المعنية، المثال القرآني، الاستثناءات).
